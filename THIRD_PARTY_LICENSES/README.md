# Third-party license texts

The Go and workbench distributions contain third-party software under the licenses copied into these directories. The package and license index is in [`../THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).

Refresh the inventory after changing Go or npm dependencies with `make licenses`. CI regenerates the files and checks that the committed inventory is current. Unknown or unapproved Go and workbench licenses fail the refresh.
